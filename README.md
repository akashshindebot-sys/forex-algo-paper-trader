# Forex Algo Paper Trader

A multi-pair forex algorithmic trading project.

## Project goals
- Start with EURUSD and support other available forex pairs.
- Use 15-minute candles (M15).
- Test a 20/50 moving-average crossover strategy.
- Backtest historical market data.
- Track simulated trades and profit/loss.
- Apply risk limits and daily loss protection.
- Keep all trading in backtests and demo/paper mode.

## Supported pairs
- EURUSD
- GBPUSD
- USDJPY
- AUDUSD
- USDCAD

Only use symbols supported by the selected data source.

## Safety
- No live orders.
- No real-money trading.
- Never commit passwords, API keys, or access tokens.
- Test strategies before considering any further deployment.
